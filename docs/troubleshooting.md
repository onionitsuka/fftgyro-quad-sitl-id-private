# 導入・起動で困ったとき

## Pythonがない／古い

Python 3.11以上を導入してください。Windowsでは `py -3 --version`、Mac/Linuxでは `python3 --version` で確認できます。Windowsで `python` がストアを開く場合は `py -3` を使います。
Ubuntu系でvenv作成に失敗する場合は、そのPython版に対応する `python3-venv` パッケージを導入してください。

## 初回のパッケージ導入が止まる

ネット接続・プロキシ設定を確認し、`python3 run.py setup`（Windows：`py -3 run.py setup`）を再実行します。エラーの最後だけでなく、その直前のパッケージ名を確認してください。SSL検証を無効にする必要はありません。

## 以前は動いたが起動できなくなった

`python3 run.py doctor` で専用環境のPythonとパッケージを確認します。Pythonを更新したりフォルダを移動した場合は、`.venv` を `.venv-old` に名前変更してランチャーを再実行すると、新しい環境を作れます。計算結果は `results/` に残ります。

## ポートが使用中

すでに起動しているターミナルとブラウザを使ってください。別のインスタンスを起動する場合は `python3 run.py interactive --port 8766` とし、表示されたURLを開きます。

## ブラウザが開かない／切断された

ターミナルの `Simulator:` 行に表示されたURLを開きます。サーバーが動いていれば画面の「再接続」で状態を取得し直せます。サーバー自体を終了した場合、未保存の飛行記録は失われます。自動復旧や自動保存は行いません。

## プロポが認識されない

OSからUSBジョイスティックとして認識される接続が必要です。ブラウザを前面にし、プロポのボタンを押してください。認識後に「軸割り当て・反転」の生の値を見ながら設定します。Chrome/EdgeなどGamepad APIを利用できるブラウザを使ってください。機種ごとのチャンネル順は保証していません。

## 着陸後に再開できない

このモデルはホバーからの飛行を対象とし、地面との接触・離陸を計算しません。CSVを保存して「ホバーからやり直す」を押してください。

## 出力フォルダがあるというエラー

計算は既存結果を上書きしません。新しいフォルダ名を指定します。保存済みCSVから図だけ作る場合は同じフォルダに `--plot-only` を付けます。
